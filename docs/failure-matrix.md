# Failure Matrix

Each row documents a failure condition, where it is detected, side effects performed prior to detection, retry policy, terminal state, operator remediation, and the test covering the invariant.

| Failure Condition | Detection Point | Pre-Detection Side Effects | Retry Policy | Terminal State | Operator Action | Test Reference |
|---|---|---|---|---|---|---|
| **Oversized or malformed payload** | `InboundEnvelope` validation | None | No retry. Immediate validation error. | Rejected | Inspect client request structure. | `test_models.py::TestInboundEnvelope::test_rejects_overlong_subject` |
| **Malformed email format** | `InboundEnvelope.normalize_email` | None | No retry. | Rejected | Correct source input format. | `test_models.py::TestInboundEnvelope::test_rejects_malformed_email` |
| **Timezone-naive datetime input** | `models.validate_tz_aware` | None | No retry. Validation error. | Rejected | Enforce UTC / timezone-aware timestamps. | `test_models.py::TestInboundEnvelope::test_rejects_timezone_naive_received_at` |
| **Duplicate event submission** | `dispatch.check_duplicate()` | None (prior decision already recorded) | No retry. Return prior decision. | Prior decision returned + audit event | None needed; idempotent response. | `test_e2e.py::TestDuplicateEvent` |
| **Malformed LLM triage output** | `InboundTriageResult` validation | Envelope validated | Reject output. Bounded retry in target design; quarantine in demo. | Quarantine | Inspect extraction model prompt and schema. | `test_e2e.py::TestMalformedLLMOutput` |
| **Low confidence score (< 0.85)** | `policy.evaluate_triage_decision()` | Triage completed | No retry. Route to human review. | HITL review queue | Human reviews and re-classifies inquiry. | `test_policy.py::TestLowConfidence` |
| **Prompt injection in triage draft/evidence** | `policy._has_injection_signals()` | Triage completed | No retry. Immediate quarantine. | Quarantine + audit event | Investigate sender payload and injection vector. | `test_policy.py::TestInjectionDetection` |
| **Contradictory triage fields** | `policy._has_contradictory_fields()` | Triage completed | No retry. Quarantine for investigation. | Quarantine + audit event | Review extractor accuracy on conflicting scopes. | `test_policy.py::TestContradictoryFields` |
| **Approval attempt on spam / quarantine** | `approval.approve_and_send()` | None | No retry. Immediate `ValueError`. | Command issuance rejected | Review why operator attempted approving spam. | `test_approval.py::TestApprovalEligibility::test_spam_decision_cannot_be_approved` |
| **Expected payload hash mismatch** | `approval.approve_and_send()` | None | No retry. Immediate `ValueError`. | Command issuance rejected | Ensure draft content was not altered prior to signing. | `test_approval.py::TestApprovalIssuance::test_expected_payload_hash_mismatch_fails` |
| **Approval token expired** | `approval.verify_approval()` | Dispatch attempted (audit logged) | No retry. Fail closed. | Dispatch rejected (`APPROVAL_EXPIRED`) | Operator must issue a fresh approval command. | `test_approval.py::TestExpiry::test_expired_token_fails` |
| **Approval token replayed (nonce seen)** | `approval.verify_approval()` | Dispatch attempted (audit logged) | No retry. Fail closed. | Dispatch rejected (`APPROVAL_REPLAY_REJECTED`) | Investigate duplicate trigger or replay attempt. | `test_approval.py::TestReplay::test_replay_fails`, `test_e2e.py::TestReplayedApproval` |
| **Approval signature tampered / bad secret** | `approval.verify_approval()` | Dispatch attempted (audit logged) | No retry. Fail closed. | Dispatch rejected (`APPROVAL_SIGNATURE_INVALID`) | Check token origin and shared secret configuration. | `test_approval.py::TestPayloadMutation`, `TestRecipientMutation`, `TestWrongSecret` |
| **Audit sink write failure (I/O error)** | `audit.AuditSink.log()` | Processing in progress | No retry. Raises `RuntimeError`. | Execution halts; fail-closed | Check disk space / permissions; replay from queue. | `test_audit.py::TestAuditSink::test_audit_write_failure_raises_runtime_error` |
| **Audit log tampering (hash mismatch)** | `audit.AuditSink.verify_chain()` | N/A (verification pass) | N/A | Verification returns `False` + line number | Forensically inspect file modifications. | `test_audit.py::TestAuditSink::test_tampering_detected` |
| **Missing approval secret** | `approval._get_secret()` | None | No retry. Raises `RuntimeError` at startup. | Process startup halted | Set `BEDA_APPROVAL_SECRET` environment variable. | `test_approval.py::TestMissingSecret` |
